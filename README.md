# postpixel.ai

Marketing website for PostPixel, built with Next.js, Tailwind CSS and TypeScript, and hosted on Vercel.

```bash
npm install
npm run dev        # http://localhost:3000
npm run check      # lint + typecheck + build + tests (run before every PR)
```

- **Editing copy, prices or trades:** see the `content/` folder.
- **Project rules, design system, SEO rules and the deploy workflow:** see [CLAUDE.md](./CLAUDE.md).
- **The plan and migration checklist:** see [docs/PLAN.md](./docs/PLAN.md).
